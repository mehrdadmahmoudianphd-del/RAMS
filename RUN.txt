اجرای سامانه
============

1) نصب وابستگی‌ها:
   pip install -r requirements.txt

2) اجرا فقط روی همین کامپیوتر:
   streamlit run app.py

3) اجرا برای دسترسی از موبایل/سیستم دیگر در همان شبکه وای‌فای:
   streamlit run app.py --server.address 0.0.0.0 --server.port 8501

   سپس در دستگاه دیگر آدرس زیر را باز کنید:
   http://IP-کامپیوتر-شما:8501
   (IP را با ipconfig در ویندوز یا ifconfig در لینوکس ببینید)

4) ورود آزمایشی:
   نام کاربری: admin
   رمز: admin123

5) دستیار هوشمند:
   بدون اینترنت هم با دکمه‌های نمونه و سوال متنی کار می‌کند.
